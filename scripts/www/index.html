怎么用

DeepSeek API
1. 到 DeepSeek 开放平台创建 API Key。
2. 点「API 设置」填入 Key，模型选 deepseek-flash 或 deepseek-v4-pro；再选思考强度。
3. 直接问：今天怎么吃、训练怎么调、最近体重不动怎么办。
4. 也可以把提示词复制给外部 AI，再把回答粘贴到下方保存。
AI 会自动带上你的档案、当前方案和近 7 天记录。Key 只存在本机，不会同步到云端。

💾 数据管理

建议每周备份

档案、动作库、食物库、训练、饮食、打卡、日志总结、方案和 AI 方案都会一起备份。导入会覆盖当前数据。浏览器按文件位置保存本地数据，移动文件或换浏览器前请先导出或开启云端同步。

ℹ️ 使用说明

1. 先在「我的档案」填写信息，保存后去「减脂计划」生成方案。
2. 每天按方案吃、练，记录饮食和训练；晚上或次日晨起打卡。
3. 「分析总结」看日 / 周 / 月日志、缺口和体重趋势；「顾问建议」会随近 7 天数据变化。
4. 每周复制一次迭代提示词给外部 AI，或在应用里手动记录调整。
5. 本工具不替代医生或注册营养师；有伤、孕期或慢性病请先咨询专业人士。
